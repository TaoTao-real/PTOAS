# 固定 FA：原生 VF＋PlanMemory 与代理模型 A/B 验收（2026-10-23）

本轮已完成真实 TileSim/VfSimulator 推荐、PTOAS annotation 回填、原生候选编译、受限 G2、G3 和同板性能验收。
**优化收益：AB_BENEFIT_PASS。推荐候选平均降时 33.04%。**
**模型评估：推荐候选绝对时延误差 3.36%；串行基线误差 13.31%。**
两项结论分别成立。当前使用 PR 时序参数代理 DT 硬件，G4 不认证，不自动启用。

## 1. 本轮回答了什么

我们先让模型选择，再测量冻结的候选。我们没有从新设备结果中挑选配置。
同一份 FA、同一设备、同一输入和固定存储下，PTOAS 的原生 pass 实际改变了 C/V 阶段顺序。
数值通过后，比较这个改变带来的收益。模型时延误差另行计算。

四组全部开启 PTOAS 原生 VF 与自动 PlanMemory。只改变 preload。
这不是 VF 开关消融，也不是 multi-buffer 槽数搜索。P backing 固定三槽，alpha 固定四个版本，Q 的 O/L 状态各保留四份。
P0 是相同静态展开下的串行阶段图，不是未经展开的原始循环。
因此本轮收益可以归因于这一共同链路中的 CV 重排及其必要同步，不能拆成“VF、PlanMemory、multi-buffer 各贡献多少”。

## 3. 模型在测量前推荐了什么

模型评估了 P=0/1/2/3。它返回 `p1`，即迭代距离 **P=1**。
对本轮固定的 32-token 图，其阶段顺序等价于旧工具的 **warm-up depth=2**。
不能把两个字段在任意循环上直接通用换算。

预测基线为 96.7286 μs，推荐为 72.2706 μs，预测降时 25.29%。
P=1/2/3 的预测差异都小于 0.5%，按照预定规则选择更小的 P；没有根据实测重新选择。

模型真实复用 TileSim EventEvaluator、COPY/MMAD 成本函数，以及 VfSimulator 的低层 VF 周期模型。
模型消费同一次对象编译导出的最终 VPTO、实际布局与同步，不采用假定的逻辑布局替代最终程序。
结构化输入、请求、结果、完整 Plan、对象和 launcher 通过 `ab_manifest.json` 绑定。
模型 Plan 再次回填后，annotation 文件与已编译候选逐字节相同，G1 往返通过。

冻结记录：2026-10-23 12:17:53 JST；首次新 FA launch command：12:18:52 JST。
两者的原始 UTC 时间与摘要保存在 `freeze-timeline.json`。

## 4. G2 与 G3

本轮兼容 importer 只接受上述源码 SHA。它把旧地址和行别名转换成逻辑根与相对视图。
原生 VF 准备先完成计算体融合。原生 CV pass 重排阶段。随后才运行真实 PlanMemory 与同步。
这是一条受限的固定 FA 路线，不是任意 FA 源码的通用入口。

通用 `compiler_feedback.g2_status` 仍保留 `evidence_incomplete`。本轮另有 SHA 绑定的固定 FA 受限证书，不将其提升为任意程序安全证明。

G2 包含以下证据：

- 四个候选的 SSA、local RAW/WAR/WAW、事件 ID、同步互扰和绝对依赖覆盖均通过。
- 编译器端补充校验从最终 IR 重建实际事件顺序与 flag 依赖；拒绝模型新增虚构顺序、遗漏事件或遗漏访存。安全证明不使用模型预测时间。
- 每个候选检查 3,864 个静态访问范围与 97,376 对冲突访问，核对 flag 代际和 DAG 进展。
- 两个 AIV 各自核算 VEC，不能因地址数字相同而合并存储。
- 禁用地址复用，实际地址仍由 PlanMemory 自动分配。此次没有证明通用地址复用。
- 行广播的 VLDS 会读取逻辑 row tile 后的尾部。为 11 个 row storage 根各保留物理尾部，四组使用相同布局；没有放宽边界或精度要求。

| 物理域 | 实际地址高水位 | 编译器预算 |
| --- | ---: | ---: |
| AIC MAT | 98,304 B | 524,288 B |
| AIC LEFT | 16,384 B | 65,536 B |
| AIC RIGHT | 65,536 B | 65,536 B |
| AIC ACC | 32,768 B | 262,144 B |
| 每个 AIV VEC | 72,704 B | 253,952 B |

G3 正式 **49/49** 通过。包含推荐候选首次冷启动、零、V 全 1、Q/K/V 全 1、三个 pattern 种子及两种相反顺序。
每次恢复输入、NaN 输出与 guard。独立 C++ FP64 和 NumPy FP64 golden 均通过。
全 1 等常量用例要求误差不超过 1e-6；pattern 使用 1e-4 + 1e-3 |golden|。
最大绝对误差 7.95049414703e-06；相同输入在四个候选及重复执行中输出逐字节一致。
输入未修改，guard 未修改，无超时或运行错误。

## 5. 正式同板性能结果

每组预热一次。20 个 block 使用相同种子，按四种平衡顺序轮换，取得 **80/80** profiler 样本。
每次检查输出、输入和 guard；每次恰好一个匹配 host launch symbol 的 MIX_AIC task，Block=1、Mix Block=2、device=0。
下表单位为 μs。误差定义为 `(预测−实测中位数)/实测中位数`。

| 候选 | 迭代距离 P | 本图旧 depth | 模型预测 | 实测中位数 | 实测范围 | 预测相对误差 |
| --- | ---: | ---: | ---: | ---: | --- | ---: |
| p0 | 0 | 1 | 96.7286 | 111.5785 | 109.8470–113.3100 | -13.31% |
| p1 | 1 | 2 | 72.2706 | 74.7865 | 73.0490–76.4940 | -3.36% |
| p2 | 2 | 3 | 72.2717 | 75.3770 | 74.5010–77.5270 | -4.12% |
| p3 | 3 | 4 | 72.2728 | 75.3240 | 74.1830–77.7230 | -4.05% |

主对比 `p1/p0`：

- 配对平均降时：**33.04%**。
- bootstrap 95% 区间：**32.52%–33.55%**。
- 最小配对收益：31.29%；20 个 pair 齐全，全部运行正确。
- 判定：**AB_BENEFIT_PASS**。达到平均至少 2%、区间下界大于 0、任一配对回退不超过 2% 的门槛。

## 6. 模型是否选对，预测是否准确

实测中位数排序为：`p1 → p3 → p2 → p0`。
模型排序为：`p1 → p2 → p3 → p0`。
以下比较的正数表示推荐候选比该对照更快。小于 2% 的差距不按主收益门槛认定为显著业务收益；统计区间也需单独看。

| 对照 | 推荐候选相对平均收益 | 95% 区间 |
| --- | ---: | --- |
| p0 | 33.04% | 32.52%–33.55% |
| p2 | 0.97% | 0.16%–1.84% |
| p3 | 1.07% | 0.31%–1.85% |

推荐候选绝对时延误差 **3.36%**，达到本轮 10% 参考线。
但串行基线绝对误差为 **13.31%**。
模型预测收益 25.29%，实际配对平均收益 33.04%，预测减实测为 **-7.75 个百分点**。
不能因为 B 的单点时延接近，就忽略基线和收益预测的偏差。

模型仍有明确限制：PR 参数代理 DT、实际时钟未知、标量/控制按一周期近似、VSLDB VL1 使用 VLDS 时序族，以及当前 adapter 的 cache 模式为 OFF。
这些限制没有用于否定已经测得的优化收益，但阻止本轮签发目标匹配 G4。

给 cost model 团队的反馈：

1. 优先补 DT 时序包。把硬件容量、编译器预算、时钟假设和时序参数分开管理。
2. 同时校准串行与重叠场景。重点用独立原语实验检查跨核握手、完成屏障、等待与发射成本。当前总时延偏差只能提出假设，不能直接认定某一指令是根因。
3. 独立检查本 FA 的 strided UB→L1 搬运、VSLDB 行广播，以及重复 Q block 对 K/V 的缓存影响。不要用本轮 FA 结果同时拟合所有成本。
4. 使用已保存的分项模型时间、通信等待、profiler pipe 指标与候选排序作校准输入。跨核忙时之和不能当作整 kernel 时延直接相加。
5. 参数或模型更新后，重新冻结推荐，再做新一轮测试。不得把本轮样本用于选择配置后，再将同一批数据作为验收。

## 7. 与之前结果的关系

同事此前报告的是另一目标/编译/同步条件下，旧 depth=1 到 4 降时约 28.84%。
本轮在我们原生 VF＋PlanMemory 路线上独立冻结模型推荐，测得上述收益。
两者可以支持“preload 可以使 C/V 重叠并减少等待”这一趋势，不能直接互证相同最优参数或绝对时延。
本轮没有同批运行对方分支的最优产物，不能宣布整链性能替换或优于对方。
此前 micro 手工固定 P=2 与这次模型推荐 P=1 也不是同一个实验；不能混用。
