# 原生 VF × CV × PlanMemory：固定 micro 上板消融验收（2026-10-23）

结论：**受限 micro 的 G2、G3 和机制收益验收均通过。**
B 相对原始串行 A 的配对平均时延下降 **15.46%**，相对静态展开 P0 下降 **14.81%**。
本轮实际运行了设备程序，共完成正式 G3 24 次、预热 4 次和 profiler 测量 80 次。

本轮使用测量前固定的候选，**没有接入真实 TileSim 推荐**。机制收益和模型预测能力分别报告；本轮不签发 G4。

## 1. 测试对象与冻结版本

- 编译器分支：`codex/cv-vf-planmemory-integration`。
- 实验代码提交：`f8c9cbcd0460d23c14ab605d8864829399d1b630`；原生集成起点为 `4e3a50728`，本轮新增完成条件与板测工具。
- 基础包含 MR289 VF 融合；先准备带地址参数的 VF，再执行原生 CV 调度，随后运行真实 PlanMemory 和同步插入。
- 主机：`ptoas-a5-39`，device 0，实际 SOC `Ascend950DT_9592`。
- CANN 9.2.0，inner version B091；LLVM 19.1.7；Python 3.11.6；VfSimulator OFF；核内调度关闭。
- fixture：crossing，N=8，32×32 FP32，1 AIC＋2 AIV。每轮输入不同，计算 QK=Q×K、P=-QK、PV=P×V、O=PV+P。
- 三个固定种子 0/1/2，输入为 [-2,2] 整数，以 FP32 保存。NumPy 使用独立整数矩阵计算 golden；结果要求精确相等。

已在实验前、测量后分别核对 7349 个源码文件的摘要。四组使用独立 kernel symbol，并绑定同次编译反馈、对象和 launcher 摘要。

## 2. 消融变量

| 变体 | 外层调度 | P Buffer 槽数／每 AIV | 用来检查什么 |
|---|---|---:|---|
| A | 原始串行循环 | 1 | 整体基线 |
| P0 | P=0 静态展开 | 1 | 单独展开的影响 |
| M | P=0 静态展开 | 3 | 只增加槽数的影响 |
| B | P=2、Pe=2 的 Prefix/Suffix 调度 | 3 | preload 与必要版本缓冲的组合影响 |

四组使用相同的 VF 融合和同步策略。规范化后的三段 prepared VF 体完全相同。
M 与 B 的实际物理分配表相同；B 执行调度需要的版本轮换。其他 local Buffer 均为单槽。

P=2 表示 Prefix(t) 先于 Suffix(t-2) 发射，`Pe=min(P,N)`。
由于同一步先执行 Prefix，跨阶段存活的 P 在该候选中需要三槽。
P-invalid 保持同一 preload、强制 P 为单槽，编译器按预期以 `INSUFFICIENT_SLOTS` 拒绝，未送设备执行。

## 3. G2 如何闭合

没有将通用反馈中的 `unknown` 直接改成 `pass`。本轮增加了实际完成条件和严格的受限检查：

1. 编译器在 borrowed entry 的 `tfree` 前及外层函数返回前插入 `PIPE_ALL` 完成屏障；VF 内部保留融合结果。四组均启用这一策略。
2. 同一次编译导出实际检查的 IR、物理分配及最终对象摘要。校验这些身份相互匹配。
3. 编译器绝对同步覆盖检查核对 local RAW/WAR/WAW 所需先后关系，并执行同步 ID 合法性和互扰检查。要求外层函数有非空依赖报告，且没有 uncovered 或 unmappable。
4. 对 AIC、AIV0、AIV1 的 push/pop/free 事务建立联合有向图，检查 token 对应、释放、容量和无环进展。
5. 仅接受固定生成器的精确源程序和 disjoint 参数约束。其静态分片保证 Q/K/V 读取在各轮范围内，两个 AIV 分别写入上、下半区。
6. 检查真实分配的范围、对齐和预算。本轮保守拒绝物理地址重叠，不依赖尚未证明的地址复用。

每个 AIV 的 B 版本 VEC 高水位为 75,776 字节，包含 pipe backing；两个 AIV 独立核算。
AIC 的 MAT 高水位为 40,960 字节，LEFT/RIGHT/ACC 各为 4,096 字节，均在编译器预算内。

外部证书为 `pto.cv.restricted_micro_g2.v1`。四组均通过。
**通用 compiler feedback 仍保留 `evidence_incomplete`；这里的通过只适用于该固定 micro、配置、工具链及约束。**

## 4. G3 与运行检查

正式 G3 按 B/M/P0/A 和 A/P0/M/B 两个相反顺序运行，三个种子各覆盖一次，共 24 次。
全部满足：完整输出与独立 golden 精确相等、重复输出稳定、输入未修改、输入和输出两端 guard 未修改、无运行错误或超时。

每次重新分配并恢复输入与输出哨兵。所有 profiler 运行也执行相同检查。
静态分片范围检查和 GM guard 共同构成证据；不将 guard 单独当作所有越界情况的证明。

## 5. 实际性能

每组预热一次。正式执行 20 个配对 block，种子按 0/1/2 循环，四种顺序轮换：
`A,B,P0,M`；`B,A,M,P0`；`P0,M,A,B`；`M,P0,B,A`。

每次 profiler 汇总必须恰好包含一个匹配 symbol 的 `MIX_AIC` task，`Block Num=1`、`Mix Block Num=2`、device 0。
主指标为该 task 的 `Task Duration(us)`；launcher 和 profiler 的 wall time 单独保留，不作为 kernel 时延。

| 变体 | 样本数 | 平均时延 μs | 中位数 μs | 最小–最大 μs |
|---|---:|---:|---:|---:|
| A | 20 | 18.8627 | 18.7775 | 18.1900–19.6180 |
| P0 | 20 | 18.7164 | 18.6640 | 18.2780–19.1260 |
| M | 20 | 18.5781 | 18.5970 | 17.8360–19.2990 |
| B | 20 | 15.9414 | 15.9650 | 15.4080–16.4860 |

收益按每个 block 的 `1-candidate/baseline` 计算后取平均，因此与两组平均时延直接相除略有不同。
bootstrap 使用 10,000 次重采样、固定种子 20260916，得到配对平均收益的 95% 区间。

| 比较 | 配对平均收益 | 95% 区间 | 含义 |
|---|---:|---:|---|
| B/A | 15.46% | [14.49%, 16.52%] | 组合优化相对串行 |
| B/P0 | 14.81% | [13.84%, 15.80%] | 扣除单独展开后的组合效果 |
| M/P0 | 0.73% | [-0.14%, 1.59%] | 仅增加槽数 |
| P0/A | 0.74% | [-0.40%, 1.86%] | 仅静态展开 |
| B/M | 14.17% | [13.18%, 15.14%] | 相同物理分配下的调度与版本轮换效果 |

**归因结论：**

- P0/A 的区间包含 0，单独展开没有显示稳定收益。
- M/P0 的整个区间位于 [-2%,+2%]，符合约定的无实质收益区间；多分配两槽本身没有带来本轮约 15% 的收益。
- B/P0 的区间全部大于 0，B/M 也显示稳定收益。四组 VF 体相同、M/B 分配表相同，证据支持收益来自 **preload 调度与必要版本缓冲的配合**。
- 单槽 preload 被静态检查拒绝，因此不能虚构它的上板时延，也不能把组合收益拆成“preload 单独 X%”和“multi-buffer 单独 Y%”。
- Cube 侧仍为单槽，本轮不是所有 Buffer 的性能型多槽搜索，也没有单独测 VF 融合收益。

按冻结门槛，结果为 **MECHANISM_BENEFIT_PASS**：B/A 和 B/P0 平均收益均≥2%，95% 下界均>0，所有配对均无回退；两组最小单对收益分别为 11.66% 和 11.32%。M/P0 的区间满足 ±2% 条件，P-invalid 正确拒绝，所有运行正确。
M/P0、P0/A 个别配对仍有波动，原始样本全部保留，没有删除离群点或重选候选。

## 6. 模型评估与反馈

**优化机制已在设备上产生实际收益；真实 TileSim 推荐和预测精度本轮尚未验收。**
本轮 B 是测量前固定的编译器候选，不是 TileSim 的新 prepared-VF adapter 输出。
没有对应的模型预测时延，因此不计算误差，不把缺失值当作 0，也不签发 G4。

提供给 cost model 团队的后续输入包括：同一候选的显式 schedule、完整逐 Buffer 槽数、实际布局、完成屏障和其他同步、20 组逐对时延及原始 profiler。
模型应先消费这些新增执行约束，再对同一候选重评；不能直接套用旧固定地址或另一同步策略的预测。
本轮实测适合作为后续独立验证数据，不应用它反向挑选本轮候选或校准后再声称本轮预测通过。
